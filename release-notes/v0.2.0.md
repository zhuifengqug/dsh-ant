# v0.2.0 — 玄驹：吸收上游 0.1.30，适配 Harness 0.2.2-rc.3

## 中文

- 全量吸收上游 0.1.30：适配 Harness `0.2.2-rc.2` 的子代理树契约（`manager.deliverToMember` + `rootOf` + `resident`），修复该版把旧的宿主投递入口拆掉后插件无法启用的问题。
- 成员创建、任务排队、步边界消息与冷恢复改走树契约，成员模型、推理力度与工具范围保持不变；定向停止只清理选中成员及其后代，退役成员在模型与网页两路都被拦。
- 成员已回报完成后不再重复唤醒队长：`subagent-settled` 的结构化 `stopReason` 成为结算判据，失败与缺失回报仍会通知。
- 开发宿主切到 Harness `0.2.2-rc.3`：核验其子代理运行时仍保留 `rootOf` / `prompt` / `startActivation` / `manager.resident` / `deliverToMember` 这套形状，与 rc.2 同构。
- 本分支四件定制随之上移：中文语言约束（团队提示词与全部工具参数描述）、归档团队永久删除（绑定归属会话 + 两击确认）、无进展滑动窗口标记、质量门禁只重跑失败命令并把验收证据绑定到当前 attempt。
- 测试：新增上游三条树 ABI 用例（激活 / 退役守卫三路投递 / 定向 drain）与运行期平台用例；`verify:fork` 四套本分支用例照旧复用。

## English

- Absorbs upstream 0.1.30 in full: adapts to the Harness `0.2.2-rc.2` subagent tree contract (`manager.deliverToMember` + `rootOf` + `resident`), restoring plugin activation after that release removed the previous host delivery entry point.
- Member creation, queued assignments, step-boundary messages and cold recovery now flow through the tree contract while model, reasoning effort and tool restrictions stay intact; a targeted stop clears only the selected branch, and retired members stay blocked on both model and browser paths.
- No duplicate captain wakeup once a member has already reported completion: the structured `stopReason` of `subagent-settled` decides settlement, while failures and missing reports still notify.
- Development host moves to Harness `0.2.2-rc.3`, whose subagent runtime keeps the same `rootOf` / `prompt` / `startActivation` / `manager.resident` / `deliverToMember` shape as rc.2.
- The fork's four customizations carry over: mandatory Chinese language rule in team prompts and tool descriptions, permanent deletion of archived teams (session-bound, two-step confirm), sliding no-progress markers, and verification that re-runs only failed commands with evidence bound to the current attempt.

## Install

In **Plugins → Add plugin**, enter `@zhuifengqug/dsh-ant@0.2.0`. For a CLI-managed profile, run:

```sh
dsh plugin --profile desktop add --save-exact @zhuifengqug/dsh-ant@0.2.0
```

The recommended host remains Harness `0.2.1-rc.2`; `0.2.2-rc.1` and `0.2.2-rc.2` are the preview targets covered by upstream's runtime matrix, and this fork develops against `0.2.2-rc.3`. See the [tested matrix](../compatibility.json) and the [rc.2 migration evidence](../docs/harness-0.2.2-rc.2/README.md).
