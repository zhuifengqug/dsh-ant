# v0.2.1 — 玄驹：吸收上游 0.1.31 增量 + 适配 Harness 0.2.2-rc.5

## 中文

- 宿主口径升到 Harness `0.2.2-rc.5`：`compatibility.json` 的 `recommendedHost` 改为 rc.5 并置于 recommended 轨道，rc.2 / rc.1 / 0.2.1-rc.3 降到 preview，其余保持 legacy；矩阵上限同步到 rc.5。
- 长会话不再全量复制事件：`findOwnSessionEvent`（吸收上游 #360A）改走 `session.snapshotEvents(fromSeq, toSeqExclusive)` 的 256 条分批 ranged snapshot，起点从 `Math.max(session.inheritedEventCount, fromSeq)` 算，旧宿主缺少该方法时仍有全量兜底。rc.5 的 Session 契约三个成员（`snapshotEvents` / `ownEvents` / `inheritedEventCount`）都在，无需抬依赖。
- 质量门禁拒收空任务标题（吸收上游 #307）：`task subject must not be empty`，中文描述同步。
- `agent_teams_status` 去重（吸收上游 #303）：新增 index / all 两个参数形态，同一份快照不再重复回两遍。
- parked attempt 只通知队长一次（吸收上游 #301）：同一 attempt 被反复 park 时不再刷屏，通知走 `notifyParkedAttempt` 单次记账。
- parked 后保留 attempt 记录（吸收上游 #345）：删掉会清空 `parkedAttempts` 的那条 else 分支，证据不再被后继调度抹掉。
- 计划成员的 `executionPrompt` 描述按本分支中文口径重写（上游 #360B 的 schema 变更照收，文案不照抄），兼容矩阵与安装文案按 #361 重写成本仓口径。
- 上游 0.1.31 中依赖上游编排、包名或发版面的改动不并入：本仓包名是 `@zhuifengqug/dsh-ant`，编排与发布流程自成一套。
- 测试：`pnpm build && pnpm verify` 全链路通过（含 fork 四套用例与上游回归用例）。

## English

- Host target moves to Harness `0.2.2-rc.5`: `recommendedHost` now points at rc.5 on the recommended track, rc.2 / rc.1 / 0.2.1-rc.3 fall back to preview, everything older stays legacy, and the tested matrix tops out at rc.5.
- Long sessions stop copying every event: `findOwnSessionEvent` (absorbing upstream #360A) reads through `session.snapshotEvents(fromSeq, toSeqExclusive)` in 256-event ranged batches starting at `Math.max(session.inheritedEventCount, fromSeq)`, with the old full-scan path kept as a fallback when the method is absent. All three Session members rc.5 requires exist, so no dependency bump was needed.
- Quality gates reject an empty task subject (upstream #307) with the same error string.
- `agent_teams_status` gains the de-duplicated index / all shapes from upstream #303.
- A parked attempt notifies the captain once (upstream #301) instead of on every re-park.
- Parked attempt records survive subsequent scheduling (upstream #345) because the branch that cleared `parkedAttempts` is gone.
- `executionPrompt` descriptions on planned members are rewritten in this fork's Chinese voice (upstream #360B's schema change is taken, the wording is not), and the compatibility matrix plus install copy are rewritten for this repository per #361.
- Upstream 0.1.31 changes that depend on upstream's own orchestration, package name or release surface are not merged: this fork ships as `@zhuifengqug/dsh-ant`.
- Tests: the full `pnpm build && pnpm verify` chain passes, fork suites and upstream regressions included.

## Install

In **Plugins → Add plugin**, enter `@zhuifengqug/dsh-ant@0.2.1`. For a CLI-managed profile, run:

```sh
dsh plugin --profile desktop add --save-exact @zhuifengqug/dsh-ant@0.2.1
```

Recommended host is Harness `0.2.2-rc.5`; see the [tested matrix](../compatibility.json).
